# Tablero comercial 03 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Completar el 03 como cartera privada persistente con cálculos, seguimiento, controles y PDF.

**Architecture:** Una cartera administrativa versionada conserva configuración y registros estructurados. El motor puro reproduce las reglas del Excel; la API valida y archiva; la interfaz muestra cartera y registros por secciones con edición de una oportunidad a la vez.

**Tech Stack:** Next.js/React existentes, Zod, decimal.js, Supabase/Postgres, pdf-lib y fuentes Archivo existentes; Vitest/PGlite.

**Spec:** `docs/superpowers/specs/2026-10-04-comercial-03.md`

## Global Constraints

- Acceso administrativo, backend real, RLS y archivos privados; no localStorage.
- Original y registros históricos preservados; sin importar ejemplos como cartera actual.
- Desconocido vacío, cero explícito, monedas conservadas y TC manual fechado.
- Umbral estricto y bases diferentes de priorización conservadas.
- Eventos y documentos se agregan; correcciones no borran filas previas.
- Un concepto por campo, interfaz responsive, PDF completo y justificado donde corresponda.
- No publicar ni aplicar migraciones remotas sin resolver las autorizaciones externas pendientes.

## Review Focus

1. Un asesor sin acceso global no obtiene datos por página, API, revisiones ni descarga.
2. Un corte diario que cambia no convierte una cotización antigua en una cotización nueva.
3. Registros vinculados del mismo negocio muestran la necesidad de revisar honorarios.
4. Cerrar una oportunidad preserva la cartera y sus eventos, y cancelar una tarea no equivale a cierre.
5. Un texto largo o una tabla extensa se conserva completo, con páginas y firmas de trazabilidad legibles.

- `src/lib/comercial/types.ts`: tipos, opciones y valores iniciales.
- `src/lib/comercial/schema.ts`: validación estructural y guardado de historial.
- `src/lib/comercial/calculate.ts`: motor, alertas y controles.
- `src/lib/comercial/pdf.ts`: PDF y hash de la instantánea calculada.
- Nueva migración creada con CLI: carteras, revisiones, emisiones y bucket privado.
- `src/app/api/admin/comercial/**/route.ts`: lectura, guardado, emisión y descarga administrativa.
- `src/app/admin/control-comercial/page.tsx`, `src/components/admin/comercial-*.tsx`: cartera, editor y lectura de resultados.
- Catálogo, expedientes y navegación: ruta global 03.
